# Proof Plan — SLICE-UI-00

**Theorem:** `undistortPoint_injective_zero_tangential`
**File:** `openlensio_semantics/InjectivityModel.lean`
**Date:** 2026-05-24

---

## Theorem Statement

```lean
theorem undistortPoint_injective_zero_tangential
    (k : RadialCoefficients) (p : TangentialCoefficients)
    (hp1 : p.p1 = 0) (hp2 : p.p2 = 0)
    (ε₁ ε₂ : SensorPoint)
    (h₁ : denominatorNonzero k (sensorRadius ε₁))
    (h₂ : denominatorNonzero k (sensorRadius ε₂))
    (hR : radialTerm k (sensorRadius ε₁) h₁ ≠ 0)
    (hSameR : sensorRadius ε₁ = sensorRadius ε₂)
    (hU : undistortPoint k p ε₁ h₁ = undistortPoint k p ε₂ h₂) :
    ε₁ = ε₂
```

---

## Goal Shape

Implication: from conjunction of hypotheses, conclude `ε₁ = ε₂` (two `SensorPoint`s equal).
Classification: equality of structured type — target for `SensorPoint.ext`.

---

## Opening Move

Extract x and y component equalities from `hU`:

```lean
have hX : undistortX k p ε₁ h₁ = undistortX k p ε₂ h₂ := congr_arg SensorPoint.x hU
have hY : undistortY k p ε₁ h₁ = undistortY k p ε₂ h₂ := congr_arg SensorPoint.y hU
```

**Why this fits:** `undistortPoint k p ε h = ⟨undistortX k p ε h, undistortY k p ε h⟩` definitionally,
so `SensorPoint.x (undistortPoint ...) = undistortX ...` holds definitionally.
`congr_arg` gives the component equality. This separates the 2D problem into two 1D problems.

---

## Proof Shape (Five Steps)

### Step 1 — Equate radial terms using `hSameR` and proof-irrelevance of `h`

```lean
have hRR : radialTerm k (sensorRadius ε₁) h₁ = radialTerm k (sensorRadius ε₂) h₂ := by
  simp only [radialTerm, hSameR]
```

**Why it works:** `radialTerm k r h` is defined as `numerator r / denominator r` — the `h` argument
is bound as `_` and not used in the body. After `simp only [radialTerm]` unfolds to the polynomial
fraction, `hSameR` rewrites `sensorRadius ε₁` → `sensorRadius ε₂` everywhere, making both sides
identical. Lean's simp closes with `rfl`.

### Step 2 — Transfer nonzero condition

```lean
have hR' : radialTerm k (sensorRadius ε₂) h₂ ≠ 0 := hRR ▸ hR
```

**Why it works:** `hR` says `radialTerm k (sensorRadius ε₁) h₁ ≠ 0`. Substituting `hRR` into
the type of `hR` replaces the LHS with the RHS, giving the nonzero condition for ε₂'s term.

### Step 3 — Simplify component equalities to pure radial scaling

```lean
simp only [undistortX, hp1, hp2, mul_zero, zero_mul, add_zero] at hX
simp only [undistortY, hp1, hp2, mul_zero, zero_mul, add_zero] at hY
```

**Why it works:** With `p.p1 = 0` and `p.p2 = 0`, the tangential terms vanish:
- `undistortX ... = R * ε.x + 2 * 0 * ε.x * ε.y + 0 * (...) = R * ε.x`
- `undistortY ... = R * ε.y + 0 * (...) + 2 * 0 * ε.x * ε.y = R * ε.y`

Result:
- `hX : radialTerm k (sensorRadius ε₁) h₁ * ε₁.x = radialTerm k (sensorRadius ε₂) h₂ * ε₂.x`
- `hY : radialTerm k (sensorRadius ε₁) h₁ * ε₁.y = radialTerm k (sensorRadius ε₂) h₂ * ε₂.y`

### Step 4 — Rewrite to same radial term on both sides

```lean
rw [hRR] at hX hY
```

Result:
- `hX : radialTerm k (sensorRadius ε₂) h₂ * ε₁.x = radialTerm k (sensorRadius ε₂) h₂ * ε₂.x`
- `hY : radialTerm k (sensorRadius ε₂) h₂ * ε₁.y = radialTerm k (sensorRadius ε₂) h₂ * ε₂.y`

### Step 5 — Cancel R and close with `SensorPoint.ext`

```lean
exact SensorPoint.ext (mul_left_cancel₀ hR' hX) (mul_left_cancel₀ hR' hY)
```

**Why it works:** `mul_left_cancel₀ : a ≠ 0 → a * b = a * c → b = c`.
With `hR' : radialTerm ... ≠ 0`, cancels from `hX` to get `ε₁.x = ε₂.x`,
and from `hY` to get `ε₁.y = ε₂.y`. `SensorPoint.ext` then concludes `ε₁ = ε₂`.

---

## Expected Hard Step

**Step 1 (hRR).** The `radialTerm` definition uses `_` for its proof argument, which is
the key property that allows `simp only [radialTerm, hSameR]` to close without needing
proof-irrelevance machinery. If `simp only [radialTerm, hSameR]` fails, fallback:
`unfold radialTerm; congr 1 <;> simp [hSameR]` or `unfold radialTerm; rw [hSameR]`.

## SLICE-UI-01 — undistortPoint_injective_pure_radial

### Theorem (proposed)

```lean
theorem undistortPoint_injective_pure_radial
    (k : RadialCoefficients) (p : TangentialCoefficients)
    (hp1 : p.p1 = 0) (hp2 : p.p2 = 0)
    (ε₁ ε₂ : SensorPoint)
    (h₁ : denominatorNonzero k (sensorRadius ε₁))
    (h₂ : denominatorNonzero k (sensorRadius ε₂))
    (hR₁ : radialTerm k (sensorRadius ε₁) h₁ ≠ 0)
    (hScaleInj : ∀ r₁ r₂ : ℝ, 0 ≤ r₁ → 0 ≤ r₂ →
        (radialScale k r₁)^2 * r₁^2 = (radialScale k r₂)^2 * r₂^2 → r₁ = r₂)
    (hU : undistortPoint k p ε₁ h₁ = undistortPoint k p ε₂ h₂) :
    ε₁ = ε₂
```

New helper definition required: `radialScale` — `radialTerm` without the domain condition.
New bridge lemma required: `radialTerm_eq_radialScale`.

### Goal shape

Implication. Proof by reduction to UI-00: derive `sensorRadius ε₁ = sensorRadius ε₂` from
the hypotheses, then call `undistortPoint_injective_zero_tangential`.

### Opening move

Same as UI-00: extract `hX`, `hY` via `congr_arg` on `hU` and simplify with p=0.

### Proof shape (six steps)

**Step 1** — Extract and simplify component equalities (identical to UI-00):
```
hX : R₁ * ε₁.x = R₂ * ε₂.x
hY : R₁ * ε₁.y = R₂ * ε₂.y
```

**Step 2** — Square both equalities:
```lean
have hX2 : R₁^2 * ε₁.x^2 = R₂^2 * ε₂.x^2 := by
  have h := congr_arg (· ^ 2) hX; simp only [mul_pow] at h; exact h
have hY2 : R₁^2 * ε₁.y^2 = R₂^2 * ε₂.y^2 := ...
```
Why: from `a = b`, `a^2 = b^2` by `congr_arg (·^2)`; `mul_pow` distributes the square.

**Step 3** — sensorRadius squared = component sum:
```lean
have hsr1 : (sensorRadius ε₁)^2 = ε₁.x^2 + ε₁.y^2 := by
  unfold sensorRadius; rw [Real.sq_sqrt (by positivity)]
```
Why: `sensorRadius = √(x²+y²)`, so `(sensorRadius)² = x²+y²` by `Real.sq_sqrt`.

**Step 4** — Combine to get R₁² * r₁² = R₂² * r₂² (in radialScale form):
```lean
have hSumXY : R₁^2 * (ε₁.x^2+ε₁.y^2) = R₂^2 * (ε₂.x^2+ε₂.y^2) := by nlinarith [hX2,hY2]
have hSum : (radialScale k r₁)^2 * r₁^2 = (radialScale k r₂)^2 * r₂^2 := by
  rw [hsr1, hsr2, ← hRR, ← hRR2]; exact hSumXY
```
Where `hRR`, `hRR2` come from `radialTerm_eq_radialScale`.

**Step 5** — Apply `hScaleInj` to get `sensorRadius ε₁ = sensorRadius ε₂`:
```lean
have hr := hScaleInj _ _ (sensorRadius_nonneg ε₁) (sensorRadius_nonneg ε₂) hSum
```

**Step 6** — Apply UI-00:
```lean
exact undistortPoint_injective_zero_tangential k p hp1 hp2 ε₁ ε₂ h₁ h₂ hR₁ hr hU
```

### Expected hard step

`hSumXY` via `nlinarith [hX2, hY2]`. The goal is `R₁² * (ε₁.x² + ε₁.y²) = R₂² * (ε₂.x² + ε₂.y²)`
— factored form. nlinarith should handle this from hX2 and hY2. Fallback: `ring_nf; linarith [hX2, hY2]`.

### New definitions in this slice

- `radialScale k r` — same body as `radialTerm k r _`, no domain condition. Added to `InjectivityModel.lean`.
- `radialTerm_eq_radialScale` — bridge lemma: `radialTerm k r h = radialScale k r`.

### Automation budget

| Step | Tactic | Budget |
|---|---|---|
| hX,hY simp | `simp only [undistortX/Y, ...]` | 2; same as UI-00 |
| hX2,hY2 squaring | `congr_arg (·^2)` + `simp only [mul_pow]` + `exact` | 3 each |
| hsr1,hsr2 | `unfold sensorRadius; rw [Real.sq_sqrt (by positivity)]` | 2 each; PROOF STOP if fails |
| hSumXY | `nlinarith [hX2, hY2]` | 1; fallback: `ring_nf; linarith [hX2, hY2]` |

| final | `exact undistortPoint_injective_zero_tangential ...` | 1 |

## Algebra Plan

No algebra. All steps are definitional unfolding + cancellation. `ring` is not needed.
`field_simp` is not needed (no division in the goal after unfolding). The radialTerm
division disappears because we equate the two radial terms (hRR) and then cancel as a
multiplicative factor, never needing to reason about the division itself.
